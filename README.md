# کلاینت اندروید کمیته‌های محلات جوانرود

ساخت خودکار APK از طریق GitHub Actions با Buildozer.

## ساخت APK

### به‌صورت خودکار (GitHub Actions)

با هر push به شاخه `main`، اکشن `.github/workflows/build-apk.yml`
به‌صورت خودکار اجرا و فایل APK دیباگ را به‌عنوان artifact در برگه
Actions همان اجرا (run) قابل دانلود می‌کند.

### به‌صورت محلی (لینوکس)

```bash
pip install buildozer "cython<3.0"
buildozer -v android debug
```

فایل خروجی در `bin/*.apk` قرار می‌گیرد.

## نکات فنی مهم

- **متن فارسی**: Kivy به‌صورت پیش‌فرض حروف فارسی/عربی را به‌هم
  نمی‌چسباند و ترتیب راست‌به‌چپ نمی‌دهد. تمام متن‌های فارسی باید از
  تابع `rtl_text.fa()` عبور کنند (این کار در `main.py` انجام شده است).
- **فونت**: باید فونت وزیرمتن را طبق `assets/fonts/README.md` اضافه
  کنید، وگرنه نمایش فارسی با فونت پیش‌فرض Kivy خوانا نخواهد بود.
- **شناسه دستگاه**: در نسخه اندروید، `ANDROID_ID` هم در محاسبه
  fingerprint دستگاه لحاظ شده (`client_exchange_core._android_id`)
  تا امنیت قفل دستگاه حفظ شود.
- **رمزنگاری**: `cryptography` دارای recipe رسمی در python-for-android
  است. هش رمز عبور با `hashlib.scrypt` (کتابخانه استاندارد پایتون) انجام
  می‌شود؛ `argon2-cffi` حذف شد چون recipe سازگاری برای build اندروید نداشت.
- **ذخیره‌سازی**: تمام داده‌های مجوز و رکوردهای رمزنگاری‌شده در
  فضای داخلی/خصوصی اپ اندروید نگه داشته می‌شوند (`android.private_storage`)
  تا با حذف برنامه پاک شوند و از دسترس سایر برنامه‌ها خارج باشند.
